# Vue3 响应式原理

> 这是一篇示例笔记，用于说明 `notes/{id}_{slug}.md` 的文件格式。

## 要点

- `reactive` 基于 `Proxy` 拦截 `get` / `set` / `deleteProperty` 等操作
- `ref` 通过 `RefImpl` 包装基本类型，访问时经 `get value()` 依赖收集
- 依赖收集发生在 `track`，触发更新发生在 `trigger`

## 代码片段

```js
import { ref, effect } from 'vue'

const count = ref(0)
effect(() => console.log(count.value))
count.value++ // 触发 effect 重新执行
```

## 表格

| API | 适用场景 | 返回值 |
| --- | --- | --- |
| reactive | 对象 / 数组 | Proxy |
| ref | 任意类型 | RefImpl |
